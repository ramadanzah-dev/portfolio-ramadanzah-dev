## Users

Primary: klien proyek freelance — orang/tim dengan kebutuhan proyek web atau IoT yang mencari developer untuk mewujudkannya. Sekunder: rekruter dan rekan seprofes yang menilai lewat GitHub/proyek terhubung.

## Product Purpose

Portofolio personal Ramadanzah (Web & IoT Developer). Meyakinkan pengunjung bahwa ia mampu mengirimkan solusi web modern dan sistem IoT nyata; sukses = pengunjung memulai kontak (email halo@ramadanzah.com, GitHub ramadanzah-dev, atau sosial lain).

## Positioning

Satu orang yang menjembatani dua dunia: antarmuka web yang bersih DAN perangkat keras cerdas (ESP32, sensor, MQTT). Dibuktikan proyek institusional nyata yang sudah tayang (Darmajaya), bukan klaim.

## Operating Context

Developer solo, berbahasa Indonesia, menyasar pasar berbahasa Indonesia. Pernah mengerjakan situs untuk Institut Informatika dan Bisnis Darmajaya (neliti-sk, Prodi PTI, LPM). Status "tersedia untuk proyek baru" ditampilkan di hero.

## Capabilities and Constraints

- WAJIB tetap satu file HTML statis (`index.html`) — mudah di-deploy ke hosting mana pun. Keputusan user, pegang saat semua kerjaan mendatang.
- Stack: Tailwind CSS via CDN, Inter (Google Fonts), Phosphor Icons, tema gelap/terang via class + localStorage.
- Keahlian yang diklaim di halaman: Laravel, Tailwind, Node.js, JavaScript, API Integration; ESP8266/ESP32, MQTT, C++, HTTP Post, integrasi sensor.
- Belum diputuskan: link footer LinkedIn dan X masih placeholder `#`.

## Product Principles

1. Bukti mengalahkan klaim — proyek nyata dengan tautan live selalu tampil duluan.
2. Kontak tanpa gesekan — jalur kontak jelas dan mudah dijangkau dari mana pun di halaman.
3. Dua dunia, satu orang — setiap permukaan menunjukkan rentang web + IoT.
4. Cepat dan mandiri — satu file statis adalah fitur (kecepatan, portabilitas), bukan keterbatasan.
